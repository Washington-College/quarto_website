# Data Science Portfolio Website

Welcome to your portfolio website for the Data Ethics and Practicum class!

## 🚀 Getting Started

1. **Accept the assignment** through the Classmoji link
2. **Open in Codespaces**: Click the green "Code" button → Codespaces → Create
3. **Follow the [Student Guide](STUDENT_GUIDE.md)** for complete setup instructions

## 📂 What's Included

Your portfolio includes:

- **`index.qmd`** - Home page
- **`blog.qmd`** - Blog listing page  
- **`resume.qmd`** - Resume template
- **`about.qmd`** - About page
- **`posts/`** - Your blog posts go here (includes example)
- **`templates/`** - Blog post templates
- **`_quarto.yml`** - Site configuration
- **`styles.css`** - Custom styling
- **`requirements.txt`** - Python packages (auto-installed)

## ⚡ Quick Commands

```bash
# Check Quarto installation
quarto check

# Preview your site locally
quarto preview

# Build your website
quarto render

# Deploy changes
git add .
git commit -m "Update portfolio"
git push origin main
```
