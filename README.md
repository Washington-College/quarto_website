# Intro to Data Science Portfolio

Welcome to your personal portfolio website project for **Intro to Data Science** at Washington College!

This website will host your blog posts as you "learn out loud," explore datasets, build visualizations with **R & the tidyverse**, and showcase your coursework.

---

## 🚀 Quick Start

1. **Accept the Assignment**: Follow the assignment link in **Classmoji** to create your personal repository.
2. **Open in GitHub Codespaces**: Click the green **Code** button → **Codespaces** → **Create codespace on main**.
3. **Follow the Guide**: Open **[STUDENT_GUIDE.md](STUDENT_GUIDE.md)** for a friendly, step-by-step walkthrough.

---

## ⚡ Essential Commands (Terminal)

```bash
# Preview your website locally in your browser
quarto preview

# Build your website when ready to publish
quarto render

# Save and push your changes to GitHub
git add .
git commit -m "Update portfolio"
git push origin main
```
